## 0. 背景与问题

用户先问「VWAP 均值回归策略是什么」（概念：价格显著偏离当日成交量加权平均价时反向开仓，赌它弹回 VWAP；
与 ORB 的动量/突破延续正好是同窗口的反向赌注），随后提议用现有数据快测，限定 **10:00–11:00（ET）上午场**，回答三个问题：

1. 上午偏离 VWAP 的**程度**（分布）；
2. 偏离后的**回归概率**（多快、多大比例触回 VWAP）；
3. 回归的**发生时间**分布；顺带一个粗版策略网格看能不能做出正期望。

## 1. 数据与口径

- **数据**：`ORB_strategy/nq_continuous_1m.parquet`（NQ 连续 1min，2010-06 ~ 2026-08，UTC），
  样本取 **2019-01-01 起**（与主线口径一致；2010–2015 稀疏，见持久结论 B）。共 **1,980 个交易日**。
- **VWAP 锚**：主锚 = **ETH 开盘 18:00 ET（前一日）**，即期货平台标准的"日内 VWAP"；
  敏感性锚 = RTH 9:30。session 归属用 `sess = (ts_ET + 6h).date()`，让 18:00 起的盘归属次日。
- **σ(t)**：成交量加权的 tp 对 VWAP 标准差（标准 VWAP bands）：`σ = sqrt(Σv·tp²/Σv − vwap²)`，`tp=(H+L+C)/3`。
  偏离 `dev = (close − vwap)/σ`，单位 σ；点数偏离另折 ATR14（前一日 Wilder，与 orb_core_v84 同口径）。
- **窗口**：入场观察 `[10:00, 11:00)` ET；有效 bar = 时间 < 15:55（避开结算/维护窗口，半日市自动适配）。
- **粗版策略**：窗口内首次 |dev| ≥ k → 反向入场（按突破 bar 收盘价成交）；目标 = 触碰 VWAP（按 VWAP 价成交）；
  止损 = entry ± s·σ(入场时)；同一 bar 双触按**止损**计（保守）；两者都没触发 → 最后有效 bar 收盘平。
- **成本**：MNQ 口径往返 **1.0 pt**（每边 $0.5 佣金 + 1 tick 滑点 = $1.0 ÷ $2/点 = 0.5 pt/边），
  折 R 后扣进每笔。
- **与主线相同的乐观假设**：止损按触发价成交、目标按 VWAP 价成交（无额外滑点建模）——
  即结果对真实执行只会更差，不会更好。
- 网格：k ∈ {1.0, 1.5, 2.0, 2.5} × s ∈ {1.0, 1.5, 2.0}（σ 单位）。

## 2. 开发过程与修掉的坑（审计记录）

第一版跑出了**自相矛盾的假结果**（"胜率 99%、EOD 率 99.8%、中位持仓 0 分钟"），排查后是两个真 bug：

1. **session 数组含前一晚 18:00 起的 bar**：窗口扫描不能按 `t ≥ 11:00` 提前 `break`——
   数组第一根 bar 就是 18:00，直接跳出，`first_breach` 永远返回 None。
   修法：只匹配 `10:00 ≤ t < 11:00` 的 bar，不提前退出。
2. **有效 bar 计数被误当数组下标上界**：有效 bar（<15:55）**不是数组前缀**（夜晚 bar 在数组头部且无效），
   用 `n_valid`（计数）当下界会把触碰检测/策略 walk 截断在上午中段。
   修法：上界 = 最后一个有效 bar 的**实际下标 + 1**（`upto`）。

教训与主线一致：session 级逐日遍历时，永远用实际下标而不是计数；任何"概率高得离谱"的输出先做内部一致性检查。

### 3.5 结论

1. **回归现象是真的**：破位 ≥1σ 后收盘前触回 VWAP ≈100%，一小时 50–60%，破位越大越慢。
2. **但不可兑现**：回归是"收盘前的统计属性"，不是入场后 1–2σ 路径内可拿到的钱——
   紧止损（s=1σ）54–66% 先被路径噪声打掉；放宽止损（s=2σ）止损率降到 34–40%，
   但单笔盈利/R 被稀释到正好打平。成本占比小（1pt ≈ R 的 2–3%），不是主因。
3. **同窗口互相印证**：ORB 赌突破延续有正 edge，反向赌回归 ≈0 → NQ 上午偏趋势而非均值回归，
   ORB 的 edge 是结构性的，不是运气。
4. **裁决：不开坑。** 要"救活"需要强前置过滤（趋势日/跳空/开盘 drive），但基线如此平坦，
   期望值应放很低；在 live TODO·P 清完之前不考虑投入。

## 4. 局限与口径注意

- 1min bar 内路径未知：同 bar 双触按止损计（保守），但入场按 1min 收盘价（对 tick 级实际入场略乐观）。
- 止损/目标按触发价成交（与主线回测同假设）；真实执行更差。
- 未测：趋势日过滤、12:00 提前离场（不等 VWAP 触碰）、tick 级入场、ES 上复测。
- 引用数字必须带口径：NQ 1min / 2019 起 / ETH 18:00 锚 / σ 单位为 VWAP bands 标准差。
