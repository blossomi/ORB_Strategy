# LucidFlex $50K 手动操作指南（ORB v8.4 · MNQ · 考核 r7 → 资金号 r14）

> **两阶段手数**：考核期 1R = $286（r7，快进快出）；**通过当天立刻降到 1R = $143（r14）**。
> 手数每天按 ATR 算（以损定仓），策略零改动。规则以 Lucid 后台为准。
> 时间 = 美东 ET（夏令时 9:00 ET = 北京 21:00）。
> 数字依据：`propfirm/README.md` §7.6（官方规则重跑）；规则来源：support.lucidtrading.com。

## 1. 每天开盘前（3 分钟）

```
① 止损pt = 0.075 × 前一日日线 ATR(14)      （TradingView ATR=RMA 同口径；参考 5~32pt，出界先核对）
② 手数   考核期: q = floor(286 ÷ (止损pt × 2))    资金号期: q = floor(143 ÷ (止损pt × 2))
          （最少 1 手；考核期 2019 约 7~19 手、2026 约 3 手；资金号期约为其一半）
③ 每笔风险 = 止损pt × 2 × q ≈ $143（资金号期）/ $286（考核期）——恒定
④ 手数上限自查：考核 ≤ 40 micro；资金号按账面利润档：< $1,000 → ≤20 micro、
   $1,000-1,999 → ≤30、≥ $2,000 → ≤40（scaling plan，收盘后更新）
⑤ 连亏预算：资金号期 $2,000 带宽 ÷ (止损pt×2×q) = 14 笔 —— 历史最大连亏 25 笔，
   所以「爆号」是常态而非意外，重置 $95 要提前预算
```

## 2. 每日时间线（ET）

| 时间 | 动作 |
|---|---|
| 前一晚/9:00 前 | 算 ①②③④⑤；确认是否半日市 |
| 9:00-9:30 | 5 分钟图记录盘前区间：9:00/05/10/15/20/25 共 6 根 K 线的高、低点，画两条线 |
| 9:30-10:10 | 逐根等 5min K 线**走完**看收盘价：> 区间高 只做多；< 区间低 只做空；区间内等下一根 |
| 触发 | 市价买入 q 手（§3），一天最多一笔，绝不反转/加仓 |
| 15:59 | **市价全平**（硬纪律） |
| 16:00 | **撤残留止损单** → 持仓 0 / 挂单 0 / 余额记表 |
| 16:05 | 日结填表（含"今日是否算 1 个提款合格日"：单日净利 ≥ $150） |

10:05 收盘仍无突破 → 当天放弃，关软件。约 25 天/年，不交易不是错过。
**Lucid 官方强平是 16:45 ET**，永远不要让它触发（16:00-16:45 的波动不在策略里）。

## 3. 下单动作（多头示例，空头镜像）

1. 突破 K 线走完确认 → **市价买 q 手**（当月合约，换月见 §5），记录成交价
2. 30 秒内挂 **Stop Market 卖出 q 手** @ 成交价 − 止损pt（tick 对齐 0.25）——
   必须服务器端订单，不要本地软止损
3. 从下一根 K 线起，每根走完检查：最高价 ≥ 成交价 + 5×止损pt → **止损单改到成交价**
   （BE+0 tick，只改这一次，之后不用盯；可挂 TradingView alert）
4. 15:55-15:59 若被 BE 打掉 → 已自动出场，持仓应为 0
5. 15:59 市价全平 → 撤残留止损单（独立 Stop Market 不会随平仓自动消失，孤儿单次日会误开仓）

**不做**：无止盈、无 trailing、不提前止损、不隔夜、不加仓、不反转。

## 4. 规则红线（收盘自查 1 分钟）——官方口径，2026-09-14 核对

| 规则 | 数值（$50K） | 自查 |
|---|---|---|
| EOD 回撤带 | $2,000，**地板 = max($48,000, 最高收盘余额−$2,000)，越过 $52,100 后永久锁在 $50,100** | 离地板 <$500 当晚想清楚 |
| **提款对地板** | **提款后 MLL 跳到锁定地板 $50,100（不回落）** → 提款=消耗缓冲，不是刷新缓冲 | 提款前先算「提完还剩多少缓冲」 |
| 日亏上限 | **无**（LucidFlex 评测与 funded 都无 DLL） | 不用自查；风险全在 EOD 地板 |
| consistency（考核期） | 最大单日利润 ÷ 账户利润 ≤ **50%** | 临近 $3,000 自查占比；超标 → 继续交易几天稀释（经验 6-12 天） |
| payout（funded） | 每 cycle 需 **5 个单日净利 ≥$150** 的日子 + cycle 净利 > 0；单笔请求 **≥$500**；单次 ≤ min(利润 50%, **$2,000**)；**每号最多 5 次** | 记账时每天标注"合格日"；满 5 次后本号结束（转 LucidLive 审查） |
| 提款节奏 | **够条件就提满**（额度只有 5 次，用不掉就废）；但缓冲很薄时别硬提 | 缓冲 = 余额 − $50,100，< $1,000 时先攒 |
| scaling 手数 | funded 按账面利润档 20/30/40 micro | 收盘后更新，别在盘中超限 |
| 账号活跃 | **30 天无交易（净盈亏 <$1）→ 账号被永久删除** | 长期不用就买号别开；休假前先联系客服 |
| 强平 / 持仓 | 4:45 PM ET 全平（半日市按实际收盘）；隔夜/周末持仓禁 | 我们 15:59 自己平 |
| 工具检测 | 微观剥头皮（>50% 利润来自 ≤5 秒持仓）没收利润；HFT 禁；**对冲禁（跨账号反向也禁）** | ORB 持仓 ≥5 分钟，安全；多号时**不得反向** |
| 账号数量 | 合计 ≤10（考核+funded 合并），funded ≤5 | 别超买 |

**funded 阶段手数纪律：按 §1 公式（不要用考核期的大手数），不因盈利加码。**
**记住这个号注定会死**（$2,000 带宽 = 14R vs 策略累计 45.4R 回撤）——利润来自"提走的钱"。

## 5. 日历与异常

- **半日市**（13:00 收盘）：12:55 平仓，其余不变
- **换月**：MNQ 季月 3/6/9/12，到期前 ~1 周的周一换下季（当前 Z6 → 2026-12 中旬 H7）
- 盘前 K 线缺根（熔断/故障）→ 当天跳过
- 持仓中断线 → 手机端确认止损单还挂着，恢复后核对手数再操作
- 止损单被拒/未成交 → 立即市价平仓
- 平台全面故障 → 客服 + 第二通道看价，任何情况不留仓过夜
