## v0.1.0 — 2026-09-14

**新增**：`ORB_v8_4` cBot 首个版本（`src/ORB_v8_4/ORB_v8_4.cs`，828 行）+ 本地编译工程 + 构建/回测/模拟盘脚本 + CLI 事实笔记。

**内容**
- 逐条复刻 `ORB_strategy/orb_backtes_v8_4.py`：盘前区间 `[09:00,09:30)`、入场窗口 `[09:30,10:10)` 收盘价判突破、7.5%×前一日 14 日 Wilder ATR 止损、浮盈 N R 一次性拉保本（名义 R 口径）、持有到标签 15:55 的 K 线收盘、以损定仓 + 上限 + 反推止损三条护栏、无止盈无 trailing。
- 时间口径：`[Robot(TimeZone = TimeZones.EasternStandardTime)]` 把 algo 锁到 ET，`Bar.OpenTime` 与 `.py` parquet 的左标签口径逐位一致。
- 参数默认值取 `notebook.md` 的**锁定推荐参数**（5R / 10:10 / 0.7% / 200），**不是**磁盘上 `.py` 的实验态（7R / 10:30 / 起点 2020）——理由写进 README §5。
- 新增 `.py` 没有但实盘必需的护栏：EOD tick 级兜底平仓、换日/隔夜残留强平、重启后「今日已入场」去重（持仓 + 成交历史）、DRY_RUN 开关、区间 bar 数 ≠ 6 告警、启动时区自检与 bar 节奏自检。

**为什么**：用户要求把 v8.4 完整复刻到 cTrader 并用模拟盘跑几天；cTrader CFD 是既定的第二实盘通道（`notebook.md` §E）。

**验证到什么程度**
- ✅ 本地 `dotnet build` 零错误零警告（引用 cTrader CLI 自带的 `cAlgo.API.dll`，5.9.0.3）。
- ⏳ 未做：`.algo` 编译、cTrader 引擎回测、与 `.py` 的逐笔信号对齐、模拟盘实跑（全部需要 cTID 凭据）。

**审计后的三处修正（同一版本内）**
1. ATR 预热：重建历史时不再把「今天这根未收完的日线」并入 ATR（改为 `FinalizeDaysBefore(今日)`），对齐 `.py` 的 `atr.shift(1)` 无未来函数语义。
2. 历史深度：启动时 `LoadMoreHistory()` 尽力多拉（≤6 次，目标 ≥60 个交易日）并打印实际天数，< 42 天告警——回测有 10 年历史，cTrader 默认加载量可能不足。
3. 下单健壮性：带止损下单被拒时自动回退为「先市价成交、随后按绝对价挂止损」，并把拒绝原因打进日志。
